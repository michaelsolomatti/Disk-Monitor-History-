💾 Disk Monitor (History) — следи за дисками и храни историю

> «Знай, что происходило с твоими дисками вчера, сегодня и всегда»

**Disk Monitor (History)** — это набор консольных утилит для мониторинга дисков с сохранением истории показателей в реальном времени.  
Программа собирает данные о скорости чтения/записи, загрузке, температуре и других параметрах, сохраняя их в структурированном виде для последующего анализа.

## 🚀 Особенности
- 📊 Сбор данных: скорость чтения/записи (МБ/с), IOPS, загрузка (%), температура.
- 💾 Сохранение истории в JSON или CSV файл с метками времени.
- 📈 Вывод статистики за период: средние, максимальные и минимальные значения.
- 🎨 Цветная индикация в терминале.
- ⏱️ Настройка интервала сбора данных.
- 📋 Вывод истории в виде таблицы с фильтрацией по времени.
- 🔄 Поддержка нескольких дисков одновременно.
- 📤 Экспорт истории в CSV и JSON для внешнего анализа.

## 🛠️ Установка и запуск

Для каждого языка — минимальные зависимости.

| Язык       | Зависимости                          | Команда запуска                         |
|------------|--------------------------------------|-----------------------------------------|
| Python     | `psutil`, `colorama`                 | `python disk_monitor.py`                |
| Go         | `github.com/shirou/gopsutil/v3`      | `go run disk_monitor.go`                |
| JavaScript | `node-disk-info`, `fs`               | `node disk_monitor.js`                  |
| Java       | `oshi`                               | `javac -cp .:oshi-core.jar ... && java disk_monitor` |
| C#         | `System.Management`                  | `dotnet run`                            |
| Rust       | `sysinfo`, `serde`, `serde_json`     | `cargo run`                             |
| Ruby       | `sys-filesystem`, `json`             | `ruby disk_monitor.rb`                  |
| PHP        | `exec` + внешние утилиты             | `php disk_monitor.php`                  |
